# Aldern & Voss — built output

This directory is the compiled Vite SPA. Its source lives outside this
repository, at:

    ~/Downloads/watch portfolio project/aldern-voss 2/

Everything here is generated by `npm run build` in that project and copied in.
Nothing in this directory should be edited by hand — earlier changes were, and
a rebuild silently reverted them.

## Rebuilding

    cd "~/Downloads/watch portfolio project/aldern-voss 2"
    npm run build
    # then copy dist/ over this directory:
    #   dist/index.html      -> public/aldern-voss/index.html
    #   dist/assets/*        -> public/aldern-voss/assets/   (delete the old hashed js first)

`vite.config.js` sets `base: '/aldern-voss/'`. That is load-bearing and must
stay: src/App.jsx reads `import.meta.env.BASE_URL` to work out which of the two
mounts it is serving — /aldern-voss on the main host, or the root of
aldern-voss.64studios.design where the edge rewrites the prefix in. A build
without the base emits `/assets/…` and `/media/…`, which breaks every image and
video and leaves the router matching no route on the main-host mount.

Until 2026-09-05 the base was passed some other way and index.html's asset
paths were corrected by hand after each build. It is in the config now, so a
plain `npm run build` reproduces what ships.
